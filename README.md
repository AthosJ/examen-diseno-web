# 🛡️ ALUVA - Ropa de Trabajo y Elementos de Protección Personal (EPP)

Sitio web corporativo tipo *One-Page* desarrollado para la empresa **ALUVA**, especializada en vestuario técnico y protección industrial. Proyecto correspondiente a la Evaluación N°3 de la asignatura **Diseño Web**.

🚀 **Sitio Web Desplegado (Netlify):https://ev3disenowebaluva.netlify.app/

---

## 📌 Descripción del Proyecto
El proyecto consistió en la migración de un sitio web estático desarrollado previamente hacia un template estándar profesional (**Assan v3.8 - Classic Home**) basado en el framework **Bootstrap 4**. 

### Principales Características:
* **Diseño Responsivo:** Adaptado para dispositivos móviles, tablets y escritorios mediante *Grid System* y *Media Queries*.
* **Navegación Fluida:** Barra de navegación fija (*sticky*) con menú desplegable en móviles.
* **Secciones Integradas:** Inicio (Hero Banner), Nosotros, Misión y Visión, Catálogo en PDF, Galería de Productos y Formulario de Contacto/Cotización.
* **Recursos Descargables:** Enlace directo al Catálogo Oficial 2026 en formato PDF.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructuración semántica del contenido.
* **CSS3 / Bootstrap 4:** Diseños responsive, tarjetas UI, sistema de columnas y reglas `@media`.
* **Template Assan v3.8:** Base maquetada para entornos industriales/B2B.
* **GitHub & Netlify:** Control de versiones y despliegue continuo en la nube.
